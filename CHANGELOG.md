# Changelog

Changes listed under Unreleased are present in the current source and are not necessarily included in the latest published installer. Release notes and downloadable files are available on the [Releases page](https://github.com/SimpleCraftApp/VideoOCR-AMD/releases).

## Unreleased

- Discover AMD adapters with DXGI, check DirectX 12 eligibility, and support automatic or manual Radeon selection. GPU detection alone does not confirm OCR compatibility. ([#12](https://github.com/SimpleCraftApp/VideoOCR-AMD/pull/12))
- Apply conservative GPU-memory-aware worker limits and report adapter and DirectML diagnostics. Verify detector and recognizer execution on DirectML. ([#12](https://github.com/SimpleCraftApp/VideoOCR-AMD/pull/12))
- Add opt-in Stage 3 profiling and repeatable diagnostic benchmark tools. These tools do not themselves constitute a production speed optimization. ([#10](https://github.com/SimpleCraftApp/VideoOCR-AMD/pull/10))
- Improve the Windows installer, independent fork versioning, artifact naming, and preview-aware update checks. ([#9](https://github.com/SimpleCraftApp/VideoOCR-AMD/pull/9))
